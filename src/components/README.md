 FitLog — Workout Library

FitLog is a responsive workout library and daily workout planner. Users can explore different workouts, view workout details, add exercises to their daily plan, and save workouts for later.

 Technologies Used

 Next.js
 React
 TypeScript
 Tailwind CSS
 Lucide React
 REST API
 LocalStorage

Features

 Browse 12 different workout exercises
 View detailed information about each workout
 Add workouts to today's plan
 Save workouts for later
 View and manage today's workout plan
 Mark workouts as completed
 Remove workouts from the plan or saved list
 Sort workouts by duration, calories, or rating
 Workout plan and saved workouts are stored in LocalStorage
 Responsive design for mobile, tablet, and desktop
 Toast notifications for user actions
 Custom 404 page and loading screen
